# Agent Instructions

## Build / Run

- Install locally with `python -m pip install -e .`.
- Run the package with `python -m demo_agent_pkg`.

## Test / Verification

- Run `python -m pytest -q` before handoff.
- Check the console script with `agent-demo --help` after entry point changes.

## Constraints

- Keep examples copy-paste runnable.
- Prefer standard-library Python for fixture code.
